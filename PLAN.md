# План mdpass

Менеджер паролей: все записи лежат в одном Markdown-файле, зашифрованном мастер-паролем.
Дизайн: холст «Менеджер паролей — десктоп-дизайн» (12 экранов, 1280×800).

## Архитектура

- **Rust** хранит всё секретное: расшифровка, разбор формата, запись файла, копии, таймеры
  блокировки. Интерфейс получает список записей без секретов. Значение секрета приходит
  в интерфейс только по явному действию «показать» или «скопировать».
- **Шифрование:** формат `age` с паролем (scrypt). Файл `vault.md.age` можно расшифровать
  и стандартной утилитой `age`.
- **Интерфейс:** Svelte 5 + TypeScript, шрифты IBM Plex лежат в сборке (без сети).
- **Плагины Tauri:** `clipboard-manager` (буфер), `dialog` (выбор файлов).
- **Код:** `crates/mdpass-core` — логика без Tauri, с тестами; `src-tauri` — команды Tauri;
  `src` — интерфейс.

## Этапы

0. **Каркас.** Svelte, тема из дизайна (цвета, шрифты, кнопки, поля), переходы между
   экранами, плагины.
1. **Формат Markdown.** Разбор и сборка: `#`…`######` — разделы до шести уровней, `**название**` — запись, строки
   `ключ: значение`, `tags: [a], [b]`, `note`. Файл без изменений после разбора и сборки
   совпадает с исходным побайтно.
2. **Хранилище.** Создание, открытие, проверка пароля, атомарная запись (временный файл
   и переименование), пауза 3 с после неверного пароля, отдельная ошибка для повреждённого
   файла, стирание данных из памяти при блокировке (`zeroize`).
3. **Экраны входа.** Первый запуск, Разблокировка, Неверный пароль, Файл повреждён.
4. **Главное окно.** Список с разделами, поиск по названию и тегам, карточка
   («Карточка» / «Markdown»), показ и копирование значений, очистка буфера через 30 с,
   пустое хранилище.
5. **Редактирование.** Новая запись с шаблонами, генератор паролей, редактирование,
   удаление, диалоги удаления и несохранённых изменений, предпросмотр Markdown.
6. **Безопасность сессии.** Автоблокировка через 5 мин бездействия, блокировка при
   сворачивании, смена мастер-пароля.
7. **Резервные копии.** Копия перед каждой записью, хранится N штук, экран копий
   с разницей и восстановлением (текущая версия тоже сохраняется как копия).
8. **Импорт из Markdown.** Открытый `.md` с автоисправлениями (`teg` → `tags`, дубли
   заметок, пустые разделы), предложение удалить исходный файл.
9. **Настройки.** Параметры экрана настроек в конфиге приложения, отдельно от хранилища.
10. **Сборка под платформы.** Установщики Windows, macOS, Linux через GitHub Actions.
    Android и iOS — после того как стабилизируется десктоп.

## Состояние

Этапы 0–10 сделаны для компьютеров (Windows, macOS, Linux). Подготовка к выпуску:

- Сделано: идентификатор `io.github.valeragav.mdpass`, метка формата `<!-- mdpass:1 -->`,
  буфер под Wayland, стресс-тесты формата и импорта (proptest), перечитывание файла,
  изменённого вне приложения, недавние хранилища, переименование, горячие клавиши,
  журнал ошибок, аудит зависимостей в CI, SECURITY.md, тесты интерфейса (Playwright),
  ручной чек-лист `docs/manual-check.md`.
- Ждёт решений владельца: подпись установщиков, публикация на GitHub и CI, лицензия.
- Зависит от публикации: автообновление (нужен сервер с выпусками).
- Позже: Android и iOS.

## Правила работы

- Каждый этап — отдельный коммит с тестами.
- Rust-часть пишется через TDD.
- Демо-данные только выдуманные. Настоящие пароли не попадают в репозиторий и в дизайн.
