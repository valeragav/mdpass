Все записи лежат в одном файле, внутри — обычный Markdown: разделы заголовками, записи
жирным, поля строками `ключ: значение`. Файл шифруется мастер-паролем в стандартном формате
[age](https://age-encryption.org), поэтому его можно открыть и без mdpass, хранить в облаке
и править вручную: приложение не тронет того, что вы не меняли.

```markdown
# work
## server
**vps1 (инфра)**
ssh: deploy@203.0.113.10
password: ••••••••
tags: [work], [prod]
```

> Это небольшой личный проект. Он развивается по мере возможностей. Идеи и сообщения об
> ошибках оставляйте в [Issues](https://github.com/valeragav/mdpass/issues).

## Возможности

| | |
| --- | --- |
| 🔐 **Защита на выбор** | надёжное шифрование (scrypt 2^18), слабое для мгновенного открытия или обычный `.md` без пароля; меняется в настройках |
| 🙈 **Секреты скрыты** | значения расшифровываются в Rust и приходят в окно только по «показать» или «скопировать» |
| 📋 **Безопасный буфер** | мимо журнала буфера (Win+V), очистка через 30 секунд, при блокировке и выходе; `ssh` копируется готовой командой |
| 🗂️ **Разделы до 6 уровней** | сворачиваются, записи и целые разделы перетаскиваются мышью |
| 🔍 **Поиск и теги** | по названию, разделу, тегам и полям, но не по паролям |
| 🕒 **Резервные копии** | перед каждой записью; видно, что изменится при восстановлении; восстановление повреждённого файла |
| 📥 **Импорт** | открытого `.md`, в том числе старого вида `### запись`, с автоисправлениями |
| 🔄 **Синхронизация** | файл, изменённый Dropbox или другой копией mdpass, не затирается, а перечитывается |
| 🔒 **Автоблокировка** | по бездействию и при сворачивании окна |

## Быстрый старт

**Установщик**: скачайте файл для своей системы из
[последнего выпуска](https://github.com/valeragav/mdpass/releases/latest)
([подробнее](docs/setup.md#установка)).

**Из исходников** (нужны Rust, Node.js 22 и [зависимости Tauri](https://tauri.app/start/prerequisites/)):

```sh
git clone https://github.com/valeragav/mdpass.git
cd mdpass
npm install
npm run tauri build -- --no-bundle   # → target/release/mdpass
```

При первом запуске выберите, где лежит файл, защиту и мастер-пароль. Уже есть открытый файл
с паролями — нажмите **«У меня уже есть .md-файл»**, и записи перенесутся в новое хранилище.
