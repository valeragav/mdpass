# Ручная проверка перед выпуском

Автотесты покрывают формат, шифрование, копии и импорт (`cargo test`) и сценарии экранов
с заглушкой вместо Rust (`npm run test:ui`). Ниже то, что видно только в настоящем окне
приложения на настоящей системе. Проверять на каждой платформе перед выпуском.

Подготовка: собрать приложение (`npm run tauri build`) и установить его. Для проверок
с данными — демо-хранилище:
`cargo run -p mdpass-core --example demo_vault -- ./demo.md.age "demo-pass-123"`.

## Вход и шифрование

- [ ] Создать хранилище с надёжным шифрованием, закрыть приложение, открыть снова: просит пароль, открывается.
- [ ] Неверный пароль: сообщение и пауза 3 секунды.
- [ ] Создать хранилище без шифрования: файл `.md` открывается в любом текстовом редакторе, первая строка — `<!-- mdpass:1 -->`.
- [ ] В настройках включить шифрование: файл стал `.md.age`, в текстовом редакторе — нечитаемый текст.
- [ ] Выключить шифрование обратно: файл снова `.md` и читается.
- [ ] Испортить зашифрованный файл (дописать байт): экран «Файл повреждён», а не «неверный пароль».
- [ ] Расшифровать файл утилитой `age -d` тем же паролем: получается тот же Markdown.
- [ ] Слабое шифрование: пароль из 4 символов принимается, хранилище открывается мгновенно; надёжное требует 8 символов.
- [ ] В настройках сменить надёжное шифрование на слабое и обратно тем же паролем: файл открывается.
- [ ] Сменить мастер-пароль: старый не подходит, новый подходит.
- [ ] Вписать в открытый файл первую строку `<!-- mdpass:2 -->`: приложение отказывается его открывать и просит обновиться.
- [ ] Недавние хранилища: открыть два разных файла, на экране входа оба в списке, переключение одним кликом.

## Безопасность сессии

- [ ] Автоблокировка: поставить 1 минуту, ничего не трогать — через минуту экран разблокировки.
- [ ] Свернуть окно при включённой «Блокировать при сворачивании»: после разворачивания — экран разблокировки.
- [ ] Скопировать пароль: в буфере значение, через 30 секунд буфер пуст.
- [ ] Windows: после копирования пароля его нет в журнале буфера (Win+V).
- [ ] Скопировать пароль и сразу заблокировать: буфер очищен.
- [ ] Скопировать пароль и закрыть приложение: буфер очищен.
- [ ] Поле `ssh` копируется как `ssh user@host` и вставляется в терминал.
- [ ] Поиск находит запись по названию, разделу, тегу и обычному полю, но не по значению пароля.

## Работа с записями

- [ ] Перетащить запись мышью в другой раздел и перед другой записью; перетащить раздел внутрь другого и на верхний уровень.
- [ ] Ctrl+F, Ctrl+N, Ctrl+L в главном окне; Ctrl+S и Esc в редакторе (с русской раскладкой тоже).
- [ ] Стрелки в списке и в полях записи; Ctrl+C копирует подсвеченное поле, а выделенный мышью текст — как обычно; в поле поиска стрелки двигают курсор в тексте.
- [ ] macOS: Cmd+C, Cmd+V, Cmd+A в полях ввода; Cmd+Q закрывает приложение.
- [ ] Изменить файл хранилища вне приложения (вторая копия mdpass), затем сохранить другую запись: обе правки на месте, без вопросов.

## Синхронизация

Нужны два устройства (или две учётные записи системы) и токен облака.

- [ ] Яндекс Диск: на вкладке «Облако» вставить токен, нажать «Синхронизировать». На диске в «Приложения/mdpass» появился файл, статус — «Синхронизировано в …».
- [ ] Google Drive: то же самое; файл лежит в скрытой папке приложения.
- [ ] Второе устройство: «Открыть из облака» на первом экране, тот же мастер-пароль — те же записи.
- [ ] Изменить запись на первом устройстве: через минуту (или после «Синхронизировать сейчас») правка видна на втором.
- [ ] Без сети: изменить запись на обоих устройствах в разных полях, включить сеть — обе правки на месте.
- [ ] Изменить одно и то же поле на обоих устройствах: окно выбора версии, видно устройство и время. Проверить «Мою версию», «Версию с другого устройства» и «Оставить обе» (вторая — копией записи).
- [ ] «Отключить» и «Выйти»: токен удалён (Диспетчер учётных данных Windows / Связка ключей), файл на диске остался.

## Android

- [ ] APK из выпуска ставится, иконка с ключом не срезана маской.
- [ ] Создать зашифрованное хранилище, закрыть приложение, открыть: просит пароль, открывается за несколько секунд.
- [ ] Хранилище без шифрования создаётся и открывается без пароля.
- [ ] Положить `.md.age` в «Загрузки», на экране входа «Сменить» → выбрать файл: открывается тем же паролем.
- [ ] Импорт `.md` из «Загрузок»: записи на месте, приложение просит удалить исходный файл в «Файлах».
- [ ] Список: поиск, теги, избранное, разделы с подразделами; запись открывается отдельным экраном, «Назад» возвращает к списку.
- [ ] Скопировать пароль: уведомление, значение вставляется в другое приложение.
- [ ] Клавиатура не закрывает поле ввода в редакторе; строка состояния и вырез камеры не закрывают шапку.
- [ ] «Открыть из облака» на первом экране: хранилище с компьютера открывается; правки идут в обе стороны.
- [ ] Свернуть приложение при «Блокировать при сворачивании»: при возврате — экран разблокировки.

## Файлы и копии

- [ ] «Показать в папке» для хранилища и для папки копий открывает нужную папку.
- [ ] Восстановить копию: записи вернулись, текущая версия появилась в списке копий.
- [ ] Восстановить повреждённый файл из копии: рядом остался файл `.damaged-…`.
- [ ] Переименовать хранилище в настройках: файл и папка копий переименованы, недавние обновились.
- [ ] Импорт настоящего старого файла с `### запись`: записи на месте, после импорта предлагается удалить исходный файл.
- [ ] Импорт с первого запуска («У меня уже есть .md-файл»): сначала создаётся хранилище, затем шаг 2 — импорт.
- [ ] Импорт в хранилище, где уже есть записи: новые записи добавились, старые на месте.
- [ ] Поставить «Сколько копий хранить: 10» и сделать больше 10 правок: в списке копий не больше 10.

## Внешний вид

- [ ] Светлая тема, тема «как в системе» (переключить тему системы — приложение следует), четыре цвета акцента, три размера текста.
- [ ] Окно 960×640 (минимальное): ничего не обрезано, списки прокручиваются.

## Журнал и данные приложения

- [ ] После запуска есть `mdpass.log` в папке журналов (`%LOCALAPPDATA%\io.github.valeragav.mdpass\logs` на Windows), в нём нет паролей и значений записей.
- [ ] Если раньше стояла версия с идентификатором `com.mdpass.app`: после первого запуска настройки и резервные копии на месте.

## Установщик

- [ ] Установка, запуск из меню «Пуск» / Launchpad / меню приложений, иконка с ключом.
- [ ] Удаление приложения: хранилища не удаляются.
- [ ] Linux: копирование работает и под X11, и под Wayland.
