## Первый запуск

На экране «Создайте хранилище»:

1. **Файл хранилища.** По умолчанию `~/Documents/vault.md.age`. «Сменить» — выбрать другое место.
2. **Защита файла**: надёжное шифрование, слабое или без шифрования (см. [ниже](#защита-файла)).
3. **Мастер-пароль** дважды. Для надёжного шифрования — не короче 8 символов, для слабого — 4.
   Полоска под полем показывает, насколько пароль надёжен.
4. **«Создать хранилище»**.

Там же:

- **«У меня уже есть .md-файл»** — создать хранилище и сразу [импортировать](#импорт-из-markdown) в него открытый файл с паролями.
- **«Открыть существующее хранилище»** — выбрать готовый файл `.md.age` или `.md`.
- **«Открыть из облака»** — взять хранилище, которое уже [синхронизируется](#синхронизация-через-облако) с другого устройства.
- **Недавние хранилища** — последние пять открытых файлов, открываются одним кликом.

Мастер-пароль нельзя восстановить. Если его забыть, данные из файла не вернуть.

## Защита файла

| Защита | Файл | Открытие | Подбор пароля |
| --- | --- | --- | --- |
| Надёжное шифрование | `vault.md.age` | около секунды | очень дорогой: scrypt 2^18, 256 МБ памяти на попытку |
| Слабое шифрование | `vault.md.age` | мгновенно | в 64 раза дешевле: scrypt 2^12 |
| Без шифрования | `vault.md` | без пароля | не нужен: файл — обычный текст |

Зашифрованный файл — стандартный [age](https://age-encryption.org): его можно расшифровать
и без mdpass командой `age -d vault.md.age`.

Защиту можно сменить в **Настройки → Безопасность → Защита файла**: сменить пароль, перейти
с надёжного шифрования на слабое и обратно, выключить шифрование или включить его у открытого
файла. Имя файла меняется вместе с защитой: `vault.md` ↔ `vault.md.age`.

Что защищено и что нет, подробно — в [SECURITY.md](SECURITY.md).

## Записи

**Новая запись** — кнопка внизу списка или Ctrl+N. Раздел подставляется сам: тот, на который
нажали в списке, или раздел выбранной записи.

- **Шаблоны**: Сервер, База данных, Сайт, Токен, Пустая — набор полей для начала.
- **Поля** — пары «ключ: значение». Кнопки у поля: сгенерировать пароль, показать, скрывать
  значение (замок), удалить поле.
- **Порядок полей** меняется перетаскиванием за ручку ⋮⋮ слева от поля или Alt+↑ / Alt+↓
  в поле ввода. В файле поля запишутся в том же порядке.
- **Секретные поля** скрыты точками. Поля `password`, `token`, `secret`, `pin` и похожие
  секретны всегда, любое другое поле можно сделать секретным замком.
- **Генератор** даёт 20 символов без похожих (`l`, `I`, `1`, `o`, `O`, `0`), с буквами обоих
  регистров, цифрами и символами.
- **Теги** — через запятую, **заметка** — свободный текст.

В карточке записи:

- **Показать** — значение секрета видно, пока не нажать «Скрыть».
- **Скопировать** — значение в буфере обмена, через 30 секунд буфер очищается. Скопированное
  не попадает в журнал буфера (Win+V). Поле `ssh` копируется готовой командой `ssh user@host`.
- **Markdown** — как запись выглядит в файле (секреты скрыты, пока их не показали).
- **Редактировать** и **удалить** — удаление спрашивает подтверждение, перед ним делается
  резервная копия.

## Разделы

Разделы — заголовки `#` … `######`, вложенность до шести уровней.

- **Клик по разделу** делает его текущим (новая запись создастся в нём) и показывает
  справа его подразделы и все записи этого раздела с полями, без записей подразделов. Повторный клик
  сворачивает и разворачивает раздел, клик по стрелке слева — сразу.
- **Клик по названию записи** в этом списке открывает саму запись.
- **«Свернуть все»** над разделами сворачивает все разделы разом, «Развернуть все» —
  раскрывает обратно.
- **Ширина списка.** Правый край списка тянется мышью: от 220 до 640 пикселей. Двойной
  щелчок по краю возвращает обычную ширину. Ширина запоминается.
- **Перетаскивание мышью:**
  - запись на раздел — в конец этого раздела;
  - запись на верхнюю или нижнюю половину другой записи — перед ней или после неё;
  - раздел на другой раздел — внутрь, со всеми записями и подразделами;
  - запись на верхнюю треть раздела верхнего уровня — на верхний уровень, вне разделов;
  - раздел на верхнюю треть другого раздела — перед ним, на том же уровне. Так раздел
    поднимают на верхний уровень: отпускают над разделом верхнего уровня.
- Раздел, из которого ушла последняя запись, исчезает.

## Поиск и теги

Поиск ищет по названию, разделу, тегам и обычным полям. Значения секретных полей в поиске
не участвуют. Кнопки тегов над списком фильтруют записи по тегу. Пока идёт поиск, все
разделы раскрыты. Если тегов больше, чем помещается в две строки, остальные раскрывает
кнопка «Все теги».

## Избранное

Звёздочка рядом с «Редактировать» добавляет запись в избранное или убирает из него. То же
делает кнопка «В избранном» в редакторе записи. Избранные записи показываются списком над
разделами слева и стоят на месте, когда список разделов прокручивается. Пока идёт поиск
или выбран тег, список избранного скрыт. В нём видно пять записей, а если избранных
больше, стрелка у заголовка раскрывает его до десяти. Остальные — прокруткой внутри
избранного. Стрелки клавиатуры в свёрнутом избранном ходят по пяти видимым записям,
в раскрытом — по всем.

Порядок меняется перетаскиванием мышью внутри списка или клавишами Alt+↑ / Alt+↓. В файле
место записи — номер в строке `favorite: 2`. Записи со строкой `favorite: true` идут после
записей с номерами, в порядке файла. Новая избранная запись встаёт в конец списка.

## Формат файла

Хранилище — обычный Markdown:

```markdown
<!-- mdpass:1 -->

# work
## server
**node-a (кластер)**
ssh: deploy@203.0.113.10
password: ••••
pin_hint!: ••••
note: первая строка
  вторая строка
tags: [work], [prod]
favorite: 1
```

| Строка | Что это |
| --- | --- |
| `<!-- mdpass:1 -->` | метка версии формата, в редакторах Markdown не видна |
| `#` … `######` | раздел |
| `**название**` | запись: вся строка жирным, с начала строки |
| `ключ: значение` | поле |
| `ключ!: значение` | секретное поле с необычным именем |
| строка с отступом в два пробела | продолжение значения предыдущего поля |
| `tags: [a], [b]` | теги |
| `favorite: 1` | запись в избранном, первая по порядку; `favorite: true` — без номера, после записей с номерами |

Записи до первого заголовка лежат на верхнем уровне. Строки внутри записи, которые не
похожи на поле, сохраняются как есть. Если файл не менялся, приложение не меняет в нём ни
байта: ручные правки не теряются.

## Резервные копии

- **Когда:** перед каждой записью файла — добавление, правка, удаление, перемещение,
  импорт, смена защиты, восстановление.
- **Что:** точная копия файла до записи, защищённая так же, как файл в тот момент.
  В имени копии только время и действие, названий записей там нет.
- **Сколько:** 30 последних, старые удаляются сами. Меняется в **Настройки → Файл и копии**
  (10, 30 или 100), там же копии можно выключить.
- **Где:** в папке приложения, отдельно от хранилища (см. [ниже](#где-лежат-данные)).

**Восстановить:** Настройки → Файл и копии → «Открыть резервные копии» → выбрать копию.
Справа видно, что изменится: какие записи вернутся, пропадут или в каких изменятся поля.

- **Прежние значения.** У изменённой записи под описанием — поля с прежними значениями.
  Секреты скрыты точками: их показывает «глаз», копирует кнопка рядом, как в карточке
  записи. Так можно узнать старый пароль, ничего не восстанавливая.
- **«Вернуть запись»** — возвращает из копии только эту запись: прежние значения полей или
  запись, которую удалили. Остальные записи не меняются.
- **«Восстановить эту копию»** — возвращает всё хранилище целиком.

Перед любым восстановлением текущая версия тоже сохраняется копией, так что его можно
отменить.

**Файл повреждён:** на экране ошибки «Восстановить из резервной копии», выбрать копию,
ввести её пароль. Повреждённый файл остаётся рядом как `vault.md.age.damaged-<время>`.

Копия, сделанная до смены пароля, открывается только прежним паролем. Её можно сохранить
отдельным файлом кнопкой «Сохранить как файл…».

## Импорт из Markdown

**«Импортировать .md»** на пустом хранилище или **«У меня уже есть .md-файл»** при первом
запуске. Импорт понимает и старый вид, где записи — заголовки (`### web-01`), и превращает их
в `**web-01**`. Найденные неровности можно исправить или оставить:

- ключ `teg` станет `tags`;
- одинаковые заметки `note1`, `note2` станут одной;
- пустые разделы пропускаются;
- в слитное `ключ:значение` добавится пробел.

Справа видно, как файл ляжет в хранилище. Исходный файл не меняется; после импорта приложение
предложит удалить его: пароли в нём лежат открытым текстом.

## Синхронизация через облако

Одно хранилище можно держать на нескольких компьютерах и телефоне. Файл лежит в служебной
папке приложения на Яндекс Диске или Google Drive. Остальные файлы на диске mdpass не видит.
Синхронизировать можно только зашифрованное хранилище: в облако уходит тот же файл `.md.age`,
что лежит на диске.

**Подключить облако.** Настройки → «Облако». Выберите Яндекс Диск или Google Drive и вставьте
OAuth-токен:

- **Яндекс Диск** — создайте приложение на [oauth.yandex.ru](https://oauth.yandex.ru) с правом
  `cloud_api:disk.app_folder` (папка «Приложения/mdpass») и получите для него токен.
- **Google Drive** — в Google Cloud Console включите Drive API и выпустите OAuth-токен с правом
  `drive.appdata` (скрытая папка приложения).

Пароль от облака mdpass не видит. Токен хранится в системном хранилище паролей
(Диспетчер учётных данных Windows, Связка ключей macOS, Secret Service в Linux), на
телефоне — в личной папке приложения.

**Включить синхронизацию.** Там же нажмите «Синхронизировать». Файл появится в облаке под
тем же именем. Если такой файл там уже есть, записи объединятся.

**Второе устройство.** На первом экране — «Открыть из облака»: подключите облако, выберите
хранилище и место для его копии, затем введите мастер-пароль.

Дальше mdpass синхронизирует сам: при разблокировке, после каждого изменения и раз в минуту.
Пока открыт редактор записи, изменения из облака ждут. Статус виден на вкладке «Облако» и
в шапке списка на телефоне. «Синхронизировать сейчас» — не ждать минуту. Без сети изменения
копятся на устройстве и уходят, когда связь появится.

**Если правили на двух устройствах.** Изменения сливаются по полям: если здесь поменяли
пароль, а там логин, останутся оба. Если одно и то же поле изменили и здесь, и там,
откроется окно выбора. В нём видно, с какого устройства и когда пришла версия:

- **«Мою версию»** — оставить значение с этого устройства;
- **«Версию с другого устройства»** — взять пришедшее;
- **«Оставить обе»** — вторая версия сохранится отдельной записью.

Секреты в окне скрыты, «Показать пароли» показывает их. Пока вы не выбрали, в файле лежат
обе версии.

В начале файла появляется строка `<!-- mdpass-sync rev=… -->`. По ней mdpass понимает,
какие версии уже учтены. Удалять её не нужно, при ручной правке файла её можно не трогать.

**Отключить.** «Отключить» — хранилище больше не синхронизируется, файл в облаке остаётся.
«Выйти» — забыть токен облака.

## Телефон

mdpass для Android ставится из APK со страницы
[выпусков](https://github.com/valeragav/mdpass/releases/latest) (Android 7 и новее).

На телефоне хранилище лежит в личной папке приложения, другие приложения его не видят.
Перенести хранилище с компьютера проще всего через облако: «Открыть из облака» на первом
экране. Файл, скопированный на телефон, тоже открывается: на экране входа «Сменить» →
выберите файл, mdpass скопирует его к себе.

Список устроен как на компьютере: поиск, теги, избранное, разделы с подразделами. Запись
открывается отдельным экраном, «Назад» возвращает к списку. Замок и настройки — в шапке.
Скопированный пароль стирается из буфера так же, как на компьютере.

## Настройки

**Безопасность:** автоблокировка (1, 5, 15, 30 минут или никогда), очистка буфера
(15, 30, 60 секунд или не очищать), блокировка при сворачивании окна, защита файла.

**Файл и копии:** путь к хранилищу, «Переименовать…», «Показать в папке», резервные копии
(включить, сколько хранить, где лежат, открыть список).

**Внешний вид:** тёмная, светлая или как в системе тема, акцентный цвет, размер текста в записях.

**Горячие клавиши:** список всех сочетаний клавиш, как в разделе ниже.

## Горячие клавиши

| Где | Клавиши | Что делает |
| --- | --- | --- |
| Главное окно | Ctrl+F | поиск |
| Главное окно | Ctrl+N | новая запись |
| Главное окно | Ctrl+L | заблокировать |
| Главное окно | Ctrl+Shift+E | свернуть или развернуть все разделы |
| Список записей | ↑ ↓, Home, End | выбрать запись или раздел; избранное идёт первым |
| Список записей | → или Enter | перейти к полям записи или в список раздела справа (свёрнутый раздел раскроется) |
| Список записей | ← | свернуть раздел или перейти к разделу выше; из избранного — к его заголовку |
| Список записей | → ← или Enter на заголовке «Избранное» | раскрыть или свернуть длинный список избранного |
| Список записей | Alt+↑ / Alt+↓ на избранной записи | перенести её выше или ниже в избранном |
| Список записей | → ← или Enter на «Свернуть все» | развернуть или свернуть все разделы |
| Список записей | ↑ на первой строке | перейти в поиск; ↓ из поиска — обратно в список |
| Край списка (Tab до него) | ← → , Home, End | уже или шире, самая узкая или самая широкая |
| Поля записи или раздела | ↑ ↓, Home, End | выбрать поле, оно подсвечивается |
| Поля записи или раздела | Ctrl+C или Enter | скопировать поле |
| Поля записи или раздела | Пробел | показать или скрыть секрет |
| Поля записи или раздела | ← или Esc | вернуться в список |
| Список раздела | Enter или → на подразделе или названии записи | открыть его |
| Редактор | Alt+↑ / Alt+↓ | перенести поле выше или ниже |
| Редактор | Ctrl+S | сохранить |
| Редактор | Esc | назад (с вопросом, если есть правки) |

На macOS вместо Ctrl — Cmd. Работает и в русской раскладке. Тот же список есть в приложении:
**Настройки → Горячие клавиши**.

## Где лежат данные

| Что | Windows |
| --- | --- |
| Хранилище | где вы его создали |
| Резервные копии | `%LOCALAPPDATA%\io.github.valeragav.mdpass\backups\<файл>-<хеш пути>\` |
| Настройки | `%APPDATA%\io.github.valeragav.mdpass\config.json` |
| Журнал ошибок | `%LOCALAPPDATA%\io.github.valeragav.mdpass\logs\mdpass.log` |
| Состояние синхронизации | `%LOCALAPPDATA%\io.github.valeragav.mdpass\sync\` |
| Токен облака | Диспетчер учётных данных Windows |

На macOS и Linux — в стандартных папках приложений (`~/Library/Application Support/…`,
`~/.local/share/…`, `~/.config/…`). На Android всё — в личной папке приложения. Настройки
и журнал секретов не содержат.

## Вопросы и проблемы

**Забыл мастер-пароль.** Восстановить нельзя. Если остались копии, сделанные до смены
пароля, — они открываются прежним паролем.

**Файл правят на нескольких компьютерах.** Если файл поменяла синхронизация (Яндекс Диск,
Google Drive, Dropbox, OneDrive) или вторая копия mdpass, при следующем изменении mdpass
объединит чужие правки со своими по полям записей. Если одно и то же поле изменили
и здесь, и там, mdpass покажет оба значения и спросит, какое оставить: ваше, с другого
устройства или обе записи. Пока вы не выбрали, в файле лежат обе версии: ваша —
с пометкой «копия с этого устройства». Если вы удалили запись, а на другом устройстве
её в это время изменили, она вернётся, и mdpass спросит, удалить ли её снова.

**«Файл изменён вне приложения».** Объединить изменения не получилось: файл перешифровали
другим паролем, удалили или он не читается. Последнее изменение не записано, чтобы
не затереть чужие правки. «Перечитать файл» загрузит свежую версию, после этого
повторите изменение.

**«Файл повреждён».** Проверка целостности не прошла: файл обрезан или изменён. Это не
неверный пароль. Восстановите его из резервной копии.

**«Файл записан более новой версией mdpass».** Обновите приложение: старая версия могла бы
испортить файл нового формата.

**Приложение заблокировалось само.** Сработала автоблокировка или окно свернули. Время и
поведение меняются в настройках безопасности.
